# 策略黑名单

本文件记录已经在 Carp 中暴露出过拟合、不可解释或架构失控问题的策略实现。进行任何策略研究前必须先读本文件。

黑名单针对的是这些实现方法及其等价变体。不得通过改名、增加开关、嵌入组合条件或针对股票分流的方式重新引入。只有用户明确要求重新研究，并取得独立样本和逐日前缀验证证据后，才能从黑名单移除。

## 已禁止的架构方式

- 多策略家族并行后用动态路由、stock personality 或股票画像决定使用哪个家族。
- 在线家族 EV 路由、全局 dynamic switch、runner 画像路由和 runner 强制入场。旧实现默认关闭但保留了整套阈值、未来窗口结算、旁路和专用止损；现已连同开关删除，不得以“先关闭备用”为由恢复。
- 用白名单、黑名单、股票代码、行业名称或单只股票历史表现选择规则。
- 用 repair、forced re-entry、cooldown bypass、takeover 等旁路绕过主入场或主退出条件。
- 为修复少量坏交易持续添加布尔条件、例外窗口和专用状态机。
- 只增加配置开关而不删除失效策略；关闭开关后仍可从其他路径触发同一行为。
- 在完整历史上选最优参数后继续用同一批股票宣称泛化有效。
- 保留扫描产生的高精度阈值、狭窄参数区间或峰值/悬崖参数，例如 `0.2012`、`5.945306~6.168151`、`6.9~7.7` 一类缺少稳定邻域和市场解释的边界。
- 用大量策略开关乘以每个家族的专用参数形成组合搜索空间，再把开发集中的最佳组合当作单一策略。
- 为追回删减复杂策略后在开发集损失的少量收益，重新增加家族专用过滤、退出、冷却、修复或再入场参数。
- 收盘后才生成信号，却假设能按已经过去的同一收盘价成交；项目允许的仅是尾盘最后一分钟决策与成交的日线 `close` 近似。

## 外部候选处置

| 候选 | 结论 | 证据或原因 |
|---|---|---|
| “主力/散户 + 底底高/顶顶高 + 九转”公式直接作为正式策略 | 禁止直接引入 | 所谓主力/散户线实际只是价格和 KDJ 变换，不是真实资金流；最终 `XG` 未包含说明中的市值和热度条件，且没有卖点。搭配统一 ATR 退出的研究代理在 ALL250 为均值约 `29.8%`、中位数约 `1.5%`，不能据此替原公式发明完整策略。 |
| 将 `tick-stock-panel` 的多个内置策略并联或择优路由 | 禁止 | 会重新形成策略家族和样本内挑选。其平台突破、低波动龙头、趋势突破、RSI 中轴回踩在 ALL250 的均值约为 `13.8% / 16.3% / 8.8% / 18.6%`，未达到替换门槛。只借鉴其 T+1、费用、归因、敏感性和滚动样本外流程。[项目](https://github.com/shy3130/tick-stock-panel/tree/main) |
| Donchian 20 日突破 / 10 日低点退出 | 保留为挑战基准，不进入主策略 | 固定原式在 ALL250 为均值 `52.50%`、中位数 `9.56%`、金额盈亏比 `1.38`；未参与初筛的 34 只港股中位数 `-9.26%`，前三赢家贡献 `72.8%`，不足以替换主线。 |
| Hurst + 自定义量价质量评分叠加 | 量价分数删除后，ALL305 的均值、中位数、盈利覆盖和金额盈亏比反而改善；组合复杂度没有净收益 | 量价分数单独使用也未改善扩样结果，禁止恢复该自定义评分或换名叠加 |
| 250 日价格位置 + 斜率 + 路径效率组合门槛 | 最终组合中贡献接近零，却增加长周期参数和分支 | 已删除；不得为少数历史交易重新加回 |

“保留为挑战基准”不是黑名单解除，也不表示允许与主策略叠加。它只能作为完整替代候选重新走开发集、密封集和逐日前缀验证。

## 当前正式状态

RSI25/RSI100 + ATR20 x 3 + MA50 简化候选在固定 250 股基线上五项主指标全面退步，已经撤回。

Git tag `strategy-benchmark-20260907-stage1` 保留为相对 commit `a8dd63a` 的可复现历史基准：删除两个实际生效的慢牛窄状态屏蔽器，并删除默认关闭的在线 EV、全局动态和 runner 路由。固定 250 股正式报告为 `reports/offline_backtest_report_20260907_053200.txt`。精确审计结果为平均收益 `167.673618% -> 167.771937%`、平均回撤 `-37.134048% -> -37.131628%`、盈利股票占比 `78.0% -> 78.0%`、收益中位数 `59.201610% -> 59.201610%`、平均个股胜率 `35.985389% -> 36.002302%`、同公式总盈亏比 `2.071365 -> 2.072099`。这是小幅改善，不得描述成大幅提升。

tag `strategy-benchmark-20260907-single-strategy` 标记第二阶段单一策略 baseline。它用一个 RSI/ATR 策略替换遗留家族图，`new_strategy.py` 从受保护基线的 `20,322` 行降到 `740` 行；历史买卖家族、路由、修复/强制再入场、策略配置开关和孤立模块均已物理删除。正式 DEV250/ALL305 报告分别为 `reports/offline_backtest_report_20260907_214359.txt` 和 `reports/offline_backtest_report_20260907_214817.txt`。

该 baseline 在 DEV250 为平均收益 `145.28%`、平均回撤 `-41.18%`、盈利股票占比 `72.80%`、收益中位数 `44.67%`、平均胜率 `36.84%`、同公式盈亏比 `1.9060`。除平均胜率外，其余五项均弱于受保护原始基线，因此不得宣称性能提升。ALL305 为平均收益 `130.79%`、平均回撤 `-40.89%`、盈利股票占比 `71.48%`、收益中位数 `38.04%`、平均胜率 `36.40%`、同公式盈亏比 `1.8698`。

建立该 baseline 的理由是复杂度和跨批次稳定性，而非样本内收益：stage1 的 OLD128/NEW122 等权组合 CAGR 为 `19.82%/10.79%`，单一策略 baseline 为 `15.89%/12.69%`，新旧差距由 `9.03` 个百分点收窄到 `3.20` 个百分点；此前留出的 55 只港股由 `3.49%` 提升到 `7.78%`。但两个 holdout 已用于研究判断，不再是密封样本，仍需后续时间窗验证。

当前只保留四类可审计入场路径与六类退出路径。三个粗粒度风控档位在统一档位和两档消融中对多个分组整体退化，因此暂时保留并继续审计，不得围绕个股增加第四档或更细参数。Hurst 低阈值、自定义量价质量分、250 日路径过滤均因无贡献或负贡献删除，禁止换名恢复。
