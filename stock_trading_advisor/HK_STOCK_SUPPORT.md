# 港股支持文档

## 概述

本项目现已支持**港股**分析功能！除了原有的A股支持，您现在可以使用相同的技术指标和策略分析香港交易所上市的股票。

## 功能特性

### 1. 自动市场检测

系统会自动检测股票代码所属的市场：

- **A股**: 6位数字代码 (如 `000001`, `600519`)
- **港股**: 5位数字代码 (如 `00700`, `01810`, `09988`)
- **美股**: 字母代码 (如 `AAPL`, `TSLA`)

### 2. 港股特定配置

针对港股市场特点，系统采用了专门的验证规则：

| 参数 | A股 | 港股 |
|------|-----|------|
| 最大涨跌幅 | 20% | 50% (无涨跌停限制) |
| 最低价格 | ¥0.01 | HK$0.001 (支持仙股) |
| 最高价格 | ¥10,000 | HK$100,000 |
| 价格精度 | 2位小数 | 3位小数 |

### 3. 数据源支持

- **主要数据源**: AKShare (免费，推荐)
- **备用数据源**: yfinance (自动回退)

## 使用方法

### 基础用法

```bash
# 使用虚拟环境
source venv/bin/activate

# 分析港股 - 腾讯控股
python main.py -s 00700

# 分析港股 - 小米集团
python main.py -s 01810

# 分析港股 - 阿里巴巴-SW
python main.py -s 09988
```

### 代码格式支持

港股代码支持两种格式：

1. **5位数字格式**（推荐）
   ```bash
   python main.py -s 00700    # 腾讯控股
   python main.py -s 01810    # 小米集团
   python main.py -s 09988    # 阿里巴巴-SW
   ```

2. **带.HK后缀格式**
   ```bash
   python main.py -s 00700.HK
   python main.py -s 01810.HK
   ```

### 批量分析

```bash
# 同时分析多只港股
python main.py -b 00700,01810,09988,02318
```

## 技术指标说明

港股分析使用与A股相同的技术指标体系：

### 1. KDJ指标
- K值 < 20: 超卖区域，可能反弹
- K值 > 80: 超买区域，可能回调
- K线上穿D线: 黄金交叉，买入信号
- K线下穿D线: 死亡交叉，卖出信号

### 2. MACD指标
- DIFF上穿DEA: 多头信号
- DIFF下穿DEA: 空头信号
- 柱状图由负转正: 动能增强

### 3. 移动平均线
- MA16: 短期趋势线
- MA45: 中期趋势线
- 价格突破均线: 趋势反转信号

### 4. 顶底背离
- 底部背离: 价格创新低但指标未创新低，买入机会
- 顶部背离: 价格创新高但指标未创新高，卖出机会

## 注意事项

### 1. 市场差异
- **交易时间**: 港股交易时间为 09:30-12:00, 13:00-16:00 (HKT)
- **交易货币**: 港币 (HKD)
- **最小交易单位**: 每手股数不同（需查询具体股票）
- **涨跌幅限制**: 港股无涨跌停限制

### 2. 数据延迟
- AKShare数据可能有几分钟延迟
- 建议使用收盘后数据进行分析

### 3. 汇率影响
- 港币汇率波动会影响人民币收益
- 当前系统以港币计价，未考虑汇率转换

### 4. 风险提示
- 港股波动可能大于A股（无涨跌停限制）
- 部分仙股（低价股）波动极大，风险极高
- 回测收益不代表未来表现

## 故障排查

### 问题1: 数据获取失败
```
错误: 获取股票 00700 数据失败
```

**解决方案:**
1. 检查网络连接
2. 确认股票代码正确（5位数字）
3. 检查AKShare是否正常工作

### 问题2: 代码格式错误
```
错误: 检测到市场类型: CN-A, 股票代码: 700
```

**解决方案:**
确保港股代码是5位数字，前面补0：
```bash
# 错误
python main.py -s 700

# 正确
python main.py -s 00700
```

### 问题3: 数据验证失败
```
警告: 异常涨跌幅: 2024-03-15 (45.2%)
```

这是正常现象，因为港股无涨跌停限制，大幅波动属于正常市场行为。

## 技术实现细节

### 市场检测逻辑

```python
def _detect_market(code: str) -> str:
    if code.isdigit():
        code_num = int(code)
        # 港股: 5位数字
        if 1 <= code_num <= 99999 and len(code) == 5:
            return 'HK'
        # A股: 6位数字
        elif len(code) == 6:
            return 'CN-A'

    # 带后缀的港股
    if code.endswith('.HK'):
        return 'HK'

    return 'CN-A'  # 默认
```

### 数据获取流程

```
用户输入代码
    ↓
市场类型检测 (_detect_market)
    ↓
选择数据获取方法
    ├─ HK → _fetch_akshare_hk()
    ├─ CN-A → _fetch_akshare()
    └─ US → _fetch_yfinance()
    ↓
数据验证 (市场特定规则)
    ↓
技术指标计算
    ↓
策略分析
```
