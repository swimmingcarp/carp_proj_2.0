## 🚀 核心功能

### 1. ✨ 智能信号分析
- **买入信号检测**：基于均线、KDJ、MACD、底部背离
- **卖出信号检测**：跌破均线、MACD转负、顶部背离
- **信号强度评级**：0-5 星评分系统
- **多维度确认**：多个指标共振增加信号可靠性

### 2. 📊 策略回测
- 历史数据回测
- 计算总收益率、最大回撤、夏普比率
- 交易统计（交易次数、胜率）
- 可视化结果展示

### 3. 🎯 实用工具
- **单股分析**：详细分析单只股票
- **批量扫描**：快速筛选多只股票
- **自定义配置**：灵活调整策略参数
- **彩色输出**：友好的终端界面

### 4. ⚡ 性能优化
- **向量化计算**：使用 Pandas 内置函数
- **Numba 加速**：JIT 编译递推计算
- **性能提升**：相比原始实现快 **300-500 倍**

## 🎓 策略说明

### Mixed Strategy 核心逻辑

**买入条件**：
1. 收盘价 ≥ 16 日均线（趋势确认）
2. K 值 < 45（超卖区域）
3. 45 日均线向上（中期趋势）
4. **强制买入**：底部背离次日

**卖出条件**（满足任一）：
1. 收盘价 < 16 日均线
2. MACD < 0
3. 顶部背离信号

**风险控制**：
- 跌停保护：过滤单日跌幅 ≤ -15% 的股票
- 顶部背离期间阻止买入
- 快速止损机制
