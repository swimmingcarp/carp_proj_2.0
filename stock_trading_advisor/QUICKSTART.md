# 快速开始指南

## 🚀 5 分钟快速上手

### 第 1 步：安装依赖

```bash
cd stock_trading_advisor
pip install -r requirements.txt
```

如果安装较慢，使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第 2 步：运行示例

```bash
# 运行完整示例
python example.py

# 或直接分析股票
python main.py -s 000001
```

### 第 3 步：查看结果

程序会输出：
- ✅ 买入/卖出/持有信号
- 📊 信号强度（0-5 星）
- 📈 技术指标详情
- 💰 历史回测结果
- 💡 投资建议

## 📖 详细使用说明

### 命令行参数

```bash
# 基础用法
python main.py -s <股票代码>

# 参数说明
-s, --stock       单只股票代码 (支持A股/港股)
-b, --batch       批量股票代码列表
-c, --config      配置文件路径
--no-backtest     不显示回测结果

# 使用示例 - A股
python main.py -s 000001      # 平安银行
python main.py -s 600519      # 贵州茅台
python main.py -s sh600519    # 带前缀的代码

# 使用示例 - 港股 (新增支持!)
python main.py -s 00700       # 腾讯控股
python main.py -s 01810       # 小米集团
python main.py -s 09988       # 阿里巴巴-SW
python main.py -s 00700.HK    # 带后缀的代码
```

### 使用示例

#### 1. 分析单只股票

```bash
# 分析平安银行
python main.py -s 000001

# 分析贵州茅台
python main.py -s 600519

# 快速分析（不显示回测）
python main.py -s 000001 --no-backtest
```

#### 2. 批量分析

```bash
# 分析多只股票
python main.py -b 000001 000002 600519 601318

# 分析自选股
python main.py -b 000001 000002 000858 600036 600519
```

#### 3. 自定义配置

编辑 `config/config.yaml`，然后运行：
```bash
python main.py -s 000001 -c config/config.yaml
```

## 🔧 配置文件说明

### config/config.yaml

```yaml
# 数据源配置
data_source:
  provider: 'akshare'    # 数据源：akshare, tushare, yfinance
  cache_enabled: true     # 是否缓存数据

# 策略参数（核心）
strategy:
  init_k: 50.0           # KDJ 初始 K 值
  init_d: 50.0           # KDJ 初始 D 值
  init_date: '2018-01-02'  # 回测起始日期
  short_ma: 16           # 短期均线（买卖参考）
  mid_ma: 45             # 中期均线（趋势判断）
  k_threshold: 45        # K 值买入阈值（低于此值为超卖）
  stop_loss: -15.0       # 跌停保护（单日跌幅阈值）
  lookback_days: 100     # 背离检测回溯天数

# 回测配置
backtest:
  initial_capital: 10000  # 初始资金（元）
  start_date: '2020-01-01'  # 回测开始日期
```

### 参数调整建议

| 参数 | 默认值 | 激进策略 | 保守策略 |
|------|--------|---------|---------|
| short_ma | 16 | 10 | 20 |
| mid_ma | 45 | 30 | 60 |
| k_threshold | 45 | 50 | 40 |
| stop_loss | -15% | -20% | -10% |

## 📊 输出解读

### 信号类型

| 信号 | 含义 | 建议 |
|------|------|------|
| 📈 BUY | 买入信号 | 考虑买入或加仓 |
| 📉 SELL | 卖出信号 | 考虑卖出或减仓 |
| ✋ HOLD | 持有信号 | 维持当前仓位 |
| ➖ NO_SIGNAL | 无明确信号 | 观望 |

### 信号强度

- ⭐⭐⭐⭐⭐ (5星): 强烈推荐
- ⭐⭐⭐⭐ (4星): 推荐
- ⭐⭐⭐ (3星): 一般
- ⭐⭐ (2星): 较弱
- ⭐ (1星): 很弱

### 技术指标参考

**KDJ 指标**
- K < 20: 超卖（可能反弹）
- K > 80: 超买（可能回调）
- K 在 20-80: 正常区间

**MACD 指标**
- MACD > 0: 多头市场
- MACD < 0: 空头市场
- DIFF 上穿 DEA: 金叉（买入信号）
- DIFF 下穿 DEA: 死叉（卖出信号）

**均线系统**
- 价格 > MA16 > MA45: 多头排列
- 价格 < MA16 < MA45: 空头排列

## 🎯 实战技巧

### 1. 信号确认

不要只看单一信号，建议多维度确认：
- ✅ 买入信号 + 强度 ≥ 3 + 量能配合
- ✅ 底部背离 + K 值超卖 + 趋势向上

### 2. 仓位管理

| 信号强度 | 建议仓位 |
|---------|---------|
| 5 星 | 50%-70% |
| 4 星 | 30%-50% |
| 3 星 | 10%-30% |
| ≤2 星 | 观望 |

### 3. 止损策略

- 设置止损位：买入价 -5% ~ -8%
- 跌破 16 日均线：减仓 50%
- 顶部背离信号：清仓

### 4. 批量筛选流程

```bash
# 1. 批量分析自选股
python main.py -b 000001 000002 600519 601318 > result.txt

# 2. 查看结果，关注：
#    - 买入信号数量
#    - 信号强度排序
#    - 理由是否充分

# 3. 逐个详细分析高强度信号
python main.py -s <高强度股票代码>
```

## ⚠️ 风险提示

1. **数据延迟**：行情数据可能有延迟，请以实盘为准
2. **策略局限**：技术分析不是万能的，需结合基本面
3. **市场风险**：过去表现不代表未来，注意大盘环境
4. **仓位控制**：不要满仓操作，留有应对空间
5. **止损纪律**：严格执行止损，避免深套

## 🐛 常见问题

### Q1: 提示"获取数据失败"
**A**: 可能是网络问题或股票代码错误
- 检查网络连接
- 确认股票代码格式正确（6 位数字）
- 尝试更换数据源

### Q2: 运行很慢
**A**: 首次运行 Numba 需要编译
- 第一次运行每个函数会慢一些
- 后续运行会使用缓存，速度很快
- 批量分析建议每次不超过 20 只股票

### Q3: 信号和实盘软件不一致
**A**: 正常现象，原因：
- 技术指标参数可能不同
- 复权方式不同（前复权 vs 后复权）
- 数据源不同

### Q4: 如何保存结果
**A**: 使用输出重定向
```bash
python main.py -s 000001 > result.txt
```
